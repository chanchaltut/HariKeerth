# Brand assets — Harikeerth Infratax LLP

Masters supplied by the client, organised and renamed. Not shipped to the website directly — `scripts/build-brand-assets.py` derives the web-ready files from these.

| Folder | Contents |
| --- | --- |
| `logo/` | `harikeerth-logo.svg` (clean vector, extracted from the PDF), `harikeerth-logo-vector.pdf`, 4K transparent PNG master, horizontal lock-ups (navy & light), original PNG, 2D / 3D mock-ups |
| `stationery/` | Visiting card, letterhead, envelope and the combined stationery PDF |
| `source/` | Editable design files — `.ai`, `.psd`, `.cdr` (logo and stationery) |
| `reference/` | Services brochure supplied by the client |
| `photography/` | Licensed stock photography (Unsplash) used across the site |
| `og/` | Source HTML for the 1200×630 social share banner |

Brand colours: navy `#012E59`, gold `#C9972B` (gradient `#BB8523 → #DCB72D`), ivory `#FBF9F4`.
Typefaces on the web: Outfit (UI) and Cormorant Garamond (accents).
